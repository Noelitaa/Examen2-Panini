## Video Contents (5–10 min)

The demo covers:

1. **App walkthrough** — Login → Ticket List → Ticket Detail → Create Ticket → Status/Priority update
2. **Event-based communication** — explanation of `TicketEventBus`, how `SharedFlow` propagates changes, and how the list updates automatically without reloading
3. **Priority sorting** — live demo of changing a ticket's priority and watching it reposition in the list
4. **Feature Flags** — toggling `CREATE_TICKET_ENABLED` and `PRIORITY_UPDATE_ENABLED` and showing the effect
5. **Architecture overview** — package structure, MVVM, repository pattern, and how to plug in a real backend
6. **Future evolution** — how another engineer can continue this project
